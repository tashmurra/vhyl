# Provenance

The library is an independent Zebulon implementation drawing on TADS 3 and adv3Lite authoring concepts. Familiar class names describe related concepts; they do not imply complete compatibility or inclusion of another library's implementation.

The examples in this repository are original small programs. Regression worlds and host assertions are independently authored and use synthetic settings. Adapted TADS Guide exercises, reference games and private story documents are not included.

All included first-party source and documentation use the repository's MIT licence. External tools such as Zebulon, Rust, LLVM and platform SDKs are obtained separately and retain their own licences. Do not add material from a tutorial, game or library without reviewing its provenance and redistribution terms.
